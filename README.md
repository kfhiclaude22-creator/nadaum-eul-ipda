# 나다움을:입다 — 신청서 접수 페이지 (Vercel 배포용)

claude.ai 아티팩트에서 쓰던 기능(자동 저장, 관리자 현황판)을 Vercel에서도 그대로 쓸 수 있도록
서버리스 API(`/api/*.js`)로 다시 만든 버전입니다. 디자인·문항·일정 등은 원본 페이지와 동일합니다.

## 폴더 구성

```
index.html          원본과 동일한 디자인의 페이지 (백엔드 호출 부분만 교체)
api/submit.js        기관 신청서 제출 저장
api/lookup.js         이메일+연락처로 이전 제출 내용 조회
api/admin-list.js     관리자용 접수 현황 조회 (비밀번호 필요)
api/admin-csv.js      관리자용 CSV 다운로드 (비밀번호 필요)
package.json          의존 패키지(@upstash/redis) 정보
```

## 1. GitHub에 올리기

1. github.com에서 새 저장소(repository)를 만듭니다. (Private으로 만들어도 됩니다)
2. VS Code에서 이 폴더를 열고, 소스 제어(Git) 탭에서 커밋 → 방금 만든 저장소로 Push합니다.

## 2. Vercel 프로젝트 만들기

1. vercel.com에 GitHub 계정으로 가입/로그인합니다.
2. 대시보드에서 **Add New → Project** → 방금 올린 저장소를 선택(Import)합니다.
3. Framework Preset은 **Other**로 두고 그대로 **Deploy**를 누릅니다. (별도 빌드 설정 불필요)

배포가 끝나면 `https://[프로젝트명].vercel.app` 주소로 페이지가 열립니다. 이 시점에는
저장/관리자 기능이 아직 동작하지 않습니다. 아래 3·4단계를 마쳐야 완전히 작동합니다.

## 3. 저장소(Upstash Redis) 연결하기

접수 데이터를 저장할 곳입니다. (무료 등급으로 충분합니다)

1. Vercel 프로젝트 화면에서 **Storage** 탭 → **Create Database** (또는 Marketplace) → **Upstash** 선택
2. 안내에 따라 Redis 데이터베이스를 하나 만들고 이 프로젝트에 연결합니다.
3. 연결하면 `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` 환경변수가 자동으로 추가됩니다.

## 4. 관리자 비밀번호 설정하기

1. Vercel 프로젝트의 **Settings → Environment Variables**로 이동합니다.
2. 이름 `ADMIN_PASSWORD`, 값은 원하는 비밀번호로 추가합니다. (예: 과 내부에서만 공유하는 문구)
3. 저장 후, **Deployments** 탭에서 최신 배포를 **Redeploy**합니다. (환경변수는 재배포해야 적용됩니다)

## 사용 방법

- **기관 신청**: 공개된 페이지 주소를 공지에 그대로 쓰면 됩니다. 누구나 로그인 없이 신청서를 제출할 수 있습니다.
- **이전 제출 내용 불러오기**: 신청서 위쪽의 "이전에 제출한 내용 불러오기"를 누르고 이메일·연락처를 입력하면 이전 내용이 채워집니다.
- **관리자 현황 보기**: 페이지 맨 아래 footer의 "관리자"를 누르고 `ADMIN_PASSWORD`로 설정한 비밀번호를 입력하면 접수 현황표와 CSV 다운로드가 나타납니다. (같은 브라우저에서는 다시 묻지 않습니다)

## 참고 사항

- 신청 데이터는 담당자 이메일을 기준으로 저장됩니다. 같은 이메일로 다시 제출하면 이전 내용이 갱신(덮어쓰기)됩니다.
- "이전 제출 내용 불러오기"는 이메일과 연락처가 모두 일치해야 조회됩니다. 다만 관리자 비밀번호만큼 강한 보호는 아니므로, 아동 개인정보처럼 민감한 내용은 애초에 이 폼에 받지 않도록(현재도 그렇게 되어 있습니다) 유지해 주세요.
- 트래픽이 매우 많지 않은 한(수백~수천 건) 무료 등급 범위에서 운영 가능합니다.
